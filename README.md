# World of Dissonance Character Maker

Make a character for World of Dissonance, the Minecraft TTRPG.

**Use it:** https://world-of-dissonance.github.io/wod-character-maker/

Answer the questions (identity, race and variant, aspects, signature, Arcana trees, kit and story), then:

- **Download fillable PDF:** a two-page sheet you can keep editing in any PDF reader.
- **Copy import code:** in game, press **K** to open your character sheet and click **Import code**. It reads the code from your clipboard.

You can paste a code back into the maker (Finish > Edit a character from a code) to change a character later.

Works in current Chrome, Edge, Firefox and Safari. Everything runs in your browser; nothing is uploaded.

This page is built from the World of Dissonance mod project (`python tools/build_site.py`). Edit it there, not here.
